# חנוכיית אש ומים

A hanukkiah made for a school competition as a tribute to the artist Yaacov Agam, after his "Fire and Water" fountain in Dizengoff Square. Libi and Naomi's entry: printed in PETG and painted by hand.

Site: https://tikel1.github.io/agam-hanukkiah/

| Folder | What is in it |
|---|---|
| `hanukkiah/` | Concept |
| `model/` | Python (build123d) model of the hanukkiah and the name plaque, STL outputs and previews |
| `painting/` | Painting guide and colour bands |
| `research/` | Background on Agam and the fountain, and its colour program |
| `submission/` | Competition form, one-pager and logo |
| `video/` | The film: v1 (`final/`, superseded) and v2 (`v2/`: script, narration, animation engine, final render) |
| `viewer/` | 3D viewer page (`viewer/live/index.html`) |
| `site/` | Assets for the GitHub Pages front page (`index.html`) |

The narration scripts read the ElevenLabs key from the `ELEVEN_API_KEY` environment variable. Render stills, render parts and Python environments are not committed (see `.gitignore`).
