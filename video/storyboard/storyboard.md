## 1. ספר סגנון (style bible)

### 1.1 עקרונות
1. צורות שטוחות וגדולות. **בלי קווי מתאר, בלי שחור, בלי צללים ושיפועים** (מחקר §3.1). הכהה ביותר: נייבי.
2. פסים אנכיים, **צבע ואחריו לבן**. צורה גדולה (עיגול, דיסקה) חותכת את הפסים.
3. ספקטרום מתקדם בסדר גלגל הצבעים, לא אקראי.
4. כותרות באותיות **קו ונקודה** של הלוגו: קווים ישרים בלבד, שיפועים קלים, נקודה צבעונית בקצה העליון, נקודה בין מילים.
5. תנועה חלקה ומתונה (ease in-out). בלי קפיצות, בלי רעידות.
6. **החלטת סגנון (מהמשתמש, 26.11.2026):** אנימציית 2D מודרנית, מינימליסטית, מושפעת מאוד מאגם: צורות וקטוריות שטוחות, הרבה לבן, מעט אלמנטים בפריים, תנועה גיאומטרית נקייה (פסים, נקודות, קווים, סיבובים). הפולימורף והפסים הם המכשיר החזותי המרכזי. **הדמיות ה־3D לא שולטות:** החנוכייה צוירה מחדש כאיור שטוח (`shapes.flat_hanukkiah`, `ring_close_up`) וממלאת את סצנות 7, 8, 10 ו־11. הדמיה אחת בלבד מופיעה: צילום ההצגה של הלילה, **קטן וממוסגר בסצנה 11**, בתור "התוצאה האמיתית". סצנות 7 ו־10 לא משתמשות עוד בקבצי תמונה. **אין תצלומים של אגם או של המזרקה** (מחקר §7).

## 4. שרשרת כלים לשלב 4 (נבדק על המחשב הזה)

| כלי | מצב |
|---|---|
| **ffmpeg** | **לא מותקן** (לא ב־PATH, לא ב־chocolatey). אפשרויות: `winget install Gyan.FFmpeg` (winget 1.12 קיים), או `pip install imageio-ffmpeg` (מביא בינארי של ffmpeg, בלי התקנה במערכת). לא התקנתי, כדי לא לשנות את המחשב |
| Node | v20.18.0. אין puppeteer/playwright |
| Python מערכת | 3.12, Pillow 11.3, numpy 2.0.1, opencv 4.10, websocket-client 1.8, selenium 4.23 (אין msedgedriver) |
| `model/.venv` | Pillow 13, numpy, matplotlib, pyvista, trimesh, svgelements, svgpathtools. **אין** ffmpeg |
| CairoSVG | **מותקן אבל שבור:** אין `libcairo`. לא להשתמש |
| דפדפן | Microsoft Edge 109 (`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`) |

**מה נבדק:** Edge ב־headless מצלם SVG ל־PNG ב־1.1 ש' לפריים כשמפעילים אותו מחדש לכל פריים (איטי). דרך פרוטוקול CDP (`--remote-debugging-port` + `websocket-client`, בלי דרייבר) הצילום נמדד ב־**0.19 ש' לפריים ב־JPEG** ו־0.36 ב־PNG ב־1080p על דף סטטי, כלומר 3540 פריימים ב־11 עד 21 דקות. המדידה על דף עם אנימציה כבדה לא נעשתה.

**המלצה (שלב 4):**
1. **מנוע סצנות ב־HTML+SVG+JS** עם פונקציה דטרמיניסטית `seek(t)` (t בשניות) שמציירת את הפריים. כל סצנה = פונקציה שמקבלת התקדמות 0..1 ומחזירה SVG. אפשר להשתמש ב־`tools/shapes.py` ו־`style.py` כנקודת התחלה (הפלטה, האותיות, הטבעות, הלהבות, כבר שם). מכיוון שאין ספריית אנימציה, לכתוב easing פשוט (`easeInOut`, `easeOut`).
2. **תהליך רינדור:** סקריפט Python מפעיל Edge עם `--remote-debugging-port`, טוען את הדף, ולכל פריים קורא `seek(t)` ו־`Page.captureScreenshot` (JPEG איכות 92), ומזרים את הפריימים ל־`ffmpeg -f image2pipe -framerate 30 -i - -c:v libx264 -crf 18 -pix_fmt yuv420p`. (קוד הבדיקה: `tools/cdp_probe.py`, 30 שורות.)
3. **אימות לפני שמתחייבים:** לצלם סצנה 4 (הכבדה ביותר) 3 שניות ולמדוד זמן. אם איטי מדי, **גיבוי:** רנדר ב־Python עם Pillow+numpy ב־2× supersample (כל הצורות שלנו פוליגונים, עיגולים ומלבנים) וטקסט עברי ב־`ImageFont` (ל־Pillow אין raqm, אז להפוך מחרוזת עברית ללא ניקוד ידנית, או להשתמש ב־`python-bidi`).
4. **שימו לב:** לטעינת תמונות מקומיות וגופן נדרש `--allow-file-access-from-files`.
5. **שלב 5 (כתוביות וקריינות):** הכתוביות כ־SVG באותו מנוע (Secular One 54 px, אזור בטוח לעיל). לאודיו להכין קובץ אחד (WAV 48 kHz) ולמזג ב־`ffmpeg -i video.mp4 -i narration.wav -c:v copy -c:a aac`.

```powershell
python agam-hanukkiah\video\storyboard\tools\build.py
```
כותב את ה־SVG ל־`frames/`, מצלם PNG דרך Edge ובונה את שתי גיליונות הקשר. דורש Pillow ו־Edge. עם `--no-render` רק כותב SVG. הקבצים: `style.py` (פלטה, אותיות, כתובית), `shapes.py` (רכיבים), `scenes_a.py` (סצנות 1 עד 6), `scenes_b.py` (7 עד 11), `build.py`.
